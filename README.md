# Учёт личных расходов студента

Прототип веб-приложения для учёта личных расходов студента. Решение выполнено в виде SPA (Single Page Application) с использованием чистого HTML, CSS и Vanilla JavaScript, без использования внешних библиотек и API.

## Реализованные функции

- **Добавление расхода:** возможность указать сумму, категорию, дату и опциональное описание.
- **Ограничения ввода:** форма проверяет, что сумма положительная, а обязательные поля заполнены. При ошибке выводится понятное сообщение.
- **Список расходов:** отображение всех добавленных записей списком за выбранный месяц (от новых к старым).
- **Удаление записей:** возможность удалить любой расход из списка.
- **Итоги месяца:** автоматический пересчет общего итога и итога по каждой отдельной категории при добавлении расхода, удалении расхода или смене месяца. Сумма категорий всегда равна общему итогу.
- **Сохранение данных:** данные сохраняются локально в браузере (LocalStorage) и остаются доступными после обновления страницы или перезапуска браузера.
- **Единая валюта:** все расходы учитываются в одной валюте без конвертации (отформатированы с пробелами в качестве разделителя).

## Инструкция по запуску

Так как проект состоит из статичных файлов, для его запуска не требуется установка дополнительных пакетов, Node.js или базы данных:

1. Склонируйте репозиторий на свой компьютер:
   ```bash
   git clone <URL_репозитория>
   ```
2. Откройте файл `index.html` в любом современном веб-браузере (Chrome, Safari, Firefox и т.д.).

### (Опционально) Запуск через локальный сервер:
Если вы предпочитаете использовать локальный сервер:
- С помощью Python: `python3 -m http.server 8000`, после чего перейдите по адресу `http://localhost:8000`
- С помощью плагина Live Server в VS Code: нажмите кнопку "Go Live" в статус-баре.

## Проверочный сценарий (из ТЗ)
В приложении можно протестировать сценарий, указанный в задании:
1. Выберите текущий (или любой другой) месяц в фильтре.
2. Добавьте следующие расходы (выбирая соответствующие категории и вписывая сумму):
   - Категория: "Еда", Сумма: `1500`
   - Категория: "Транспорт", Сумма: `600`
   - Категория: "Еда", Сумма: `900`
3. Убедитесь, что справа в дашборде (или внизу на мобильных):
   - Общий итог равен `3 000`
   - Итог по категории "Еда" равен `2 400`
   - Итог по категории "Транспорт" равен `600`
4. Нажмите кнопку "Удалить" рядом с расходом на сумму `900` (Еда).
5. Убедитесь, что общий итог изменился на `2 100`, а категория "Еда" изменилась на `1 500`.
6. Обновите страницу и убедитесь, что оставшиеся два расхода сохранились в списке.

## Ограничения
- Не реализована синхронизация между устройствами (данные хранятся только в LocalStorage текущего браузера).
- Нет регистрации, авторизации и бэкенд сервера.
- Данное решение разработано исключительно в качестве прототипа для демонстрации основного пользовательского сценария.
